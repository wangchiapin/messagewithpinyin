# 漢字加拼音分享工具

> 把中文文字加上拼音，輸出成圖片或文字，方便用 LINE／WhatsApp 傳給學生

- **網址：** https://wangchiapin.github.io/messagewithpinyin/
- **Firebase 專案：** 不使用 Firebase
- **登入方式：** —
- **狀態：** 使用中
- **備註：** 純前端，無後端資料。原始碼說明見 `src/README.md`。

## 這是什麼

貼上中文，變成「漢字加拼音（或注音）」的圖片或文字，直接傳給學生。用台灣讀音，破音字會自動判斷。

## 功能

- **輸入**：貼上或打中文；有「範例」「清除」按鈕；「轉成繁體」「转成简体」可一鍵簡繁互轉。
- **拼音或注音**：可切換。
- **圖片預覽**：即時畫出加了拼音的圖片。內容太長（建議一次 10 行以內）會提示分段。
- **文字版**：「兩行（漢字＋拼音）」或「括號」兩種格式。
- **圖片設定**：底色（米黃／白底／青綠／深色／透明）、字級、拼音大小、單色或依聲調上色、楷體或黑體、可選擇在圖片下方加 IG 署名。
- **讀音可手動改**：點某個字可換讀音（候選或自己打，例如 `wo3`），還能存成「之後這個字都這樣讀」；也可以在「自訂讀音規則」裡一行一條地寫（例：`一般=yì bān`）。
- **輸出**：分享圖片、分享文字、複製文字、複製圖片、下載圖片。
- 設定與輸入的內容只存在使用者自己瀏覽器的 localStorage，沒有傳到任何伺服器。

## 讀音從哪來

拼音字典用 pinyin-pro，再套上 GoodTeacher 的語境規則（574 條）與台灣讀音、一／不變調、輕聲處理。

## 檔案結構

- `index.html`：網站本體（由 `src/` 組合出來的單一檔案，約 500KB，不要直接改它）。
- `opencc-cn2t.js`：第三方的簡體→繁體轉換字庫（opencc-js），照原樣放著即可。
- `src/`：產生 `index.html` 的原始檔、組合與測試方法，詳見 `src/README.md`。
